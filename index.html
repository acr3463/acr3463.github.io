🛡️ systemprompt-demo - Secure your AI agent infrastructure easily

Download for Windows

The systemprompt-demo provides a gateway for managing AI agents. It handles policy enforcement, keeps audit trails of requests, and tracks costs for your AI usage. The software runs as a single file on your computer and connects your desktop tools to AI models effectively.

📋 What this tool does

Managing AI agents requires oversight. This application centralizes your request logs and policies. It helps you monitor how often agents run, what data they access, and how much those operations cost. By hosting the gateway locally, you retain control over your infrastructure while maintaining compatibility with modern agentic workflows.

💻 System Requirements

  • Windows 10 or Windows 11
  • 4GB of RAM (minimum 8GB recommended)
  • Internet connection for AI model communication
  • 64-bit processor

🚀 Download and Setup

Follow these steps to install the gateway on your Windows machine:

  1. Go to the official releases page.
  2. Find the latest version in the Assets list.
  3. Select the file ending in .exe to start your download.
  4. Save the file to a folder where you keep your applications.
  5. Double-click the .exe file to launch the gateway.
  6. Windows might show a security prompt. Select "Run anyway" if the system asks you to confirm.
  7. The software will open a dashboard in your browser or as a desktop window.

⚙️ Configuration

Once you launch the app, you see a configuration screen. You define your policies here. These policies tell the gateway which agents you authorize and what actions they perform. Audit logs appear in the dashboard automatically. Every request made through the gateway gets recorded for your review.

🛠️ Support

If you encounter issues, check the logs located inside the folder where you saved the application. You can report bugs by opening a new issue on the GitHub repository page. Include the version number shown in the application footer for faster help.
