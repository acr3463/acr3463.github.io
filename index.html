📖 What is NepaliLang?

NepaliLang is a brand-new programming language that lets you write code in Nepali! It's designed to be easy for beginners and powerful for experienced developers. Think of it like Python, but with Nepali words for commands, making it incredibly natural for Nepali speakers to learn coding.

Created by Diwas Khatri, NepaliLang is perfect for anyone who wants to start their coding journey in their mother tongue. It comes with everything you need to write, test, and run your own programs.

✨ Amazing Features

  • 🗣️ Nepali Keywords: Write commands in Nepali like छाप्नुहोस् (print) instead of "print"
  • 🔤 Full Unicode Support: Use Nepali characters and symbols freely in your code
  • ⚡ Fast Bytecode VM: Runs your code efficiently without needing a slow interpreter
  • 📚 Standard Library: Ready-to-use functions and tools for common tasks
  • 💻 VS Code Extension: Color highlighting and helpful suggestions while you type
  • 🎓 Education-Friendly: Perfect for schools and beginners to start programming in Nepali

🔧 How It Works

NepaliLang takes your Nepali text and converts it into computer instructions through three simple steps:

  • 1️⃣ Compiler: Reads your Nepali code and understands what you want
  • 2️⃣ Bytecode Converter: Turns your instructions into tiny, efficient commands the computer loves
  • 3️⃣ Virtual Machine (VM): Executes those commands instantly to produce your result

This makes NepaliLang both fast and reliable, even for complex programs!

💡 Easy to Learn, Fun to Use

Here's what simple Nepali code looks like:

छाप्नुहोस्("नमस्ते संसार!")

# This prints: नमस्ते संसार! (Hello World!)

Variables work simply too:

नाम = "दिवस"

उमेर = 25

छाप्नुहोस्(नाम, "को उमेर", उमेर, "वर्ष छ।")
